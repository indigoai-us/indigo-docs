You can run HQ on your own computer for free, with no HQ account and no cloud.
You need the three things in this table.

| What | Where to get it |
|------|-----------------|
| HQ core, the open-source HQ kit (MIT license) | [github.com/indigoai-us/hq-core](https://github.com/indigoai-us/hq-core), installed with `npx create-hq` |
| The HQ CLI | [`@indigoai-us/hq-cli` on npm](https://www.npmjs.com/package/@indigoai-us/hq-cli) |
| The HQ desktop app (optional) | [hq-desktop-app releases](https://github.com/indigoai-us/hq-desktop-app/releases/latest) |

HQ's cloud features are an add-on you can turn on later. See
[What needs the cloud](#what-needs-the-cloud).

## Your files are yours

- HQ keeps your work as normal files and folders on your own computer. That
  includes your knowledge, skills, workers, projects and companies. You can open, copy, back
  up or move them with any tool.
- You own them. HQ core is MIT licensed, so you can read it and change it.
- You can stop using HQ at any time. Your files stay where they are.
- Cloud sync is optional. If you never sign in, nothing leaves your computer
  through HQ. Your AI tool, such as Claude Code, Codex or Cursor, still sends
  your prompts to its own provider under your own account.

## 1. Install HQ core and the CLI

You need Node.js and an AI coding tool such as Claude Code, Codex or Cursor.

```bash
npx create-hq --skip-sync
```

This downloads HQ core from GitHub into a folder you choose and installs the
HQ CLI globally. `--skip-sync` skips the cloud sync prompt. Nothing here asks
you to sign in.

To install only the CLI, run this command.

```bash
npm install -g @indigoai-us/hq-cli
```

## 2. Set up HQ without signing in

Open the folder in your AI tool and run `/setup`:

```bash
cd <your-hq-folder> && claude
```

When `/setup` asks "Sign in to HQ Cloud now?", answer no. The rest of setup
works without an account.

## 3. Use HQ locally

Skills, workers, projects, knowledge and companies all work from your HQ
folder. These CLI commands work with no account.

| Command | What it does |
|---------|--------------|
| `hq search <query>` | Search your HQ with the local search index |
| `hq index status`, `hq index sync` | Check and update the local search index |
| `hq reindex` | Refresh skills, the workers registry and hook wiring |
| `hq scan secrets` | Check staged changes or files for secrets before you commit |
| `hq db status`, `hq db sql`, `hq db migrate` | Use a company's local SQLite database |
| `hq install <path, git URL or npm package>` | Install a package from a local folder, a git URL, or npm |
| `hq packs`, `hq modules` | Manage installed content packs and modules |
| `hq rescue` | Update HQ core to the latest release, keeping your local edits |
| `hq doctor` | Check hooks, runtimes and setup |

## 4. The desktop app and local bots

<Aside type="caution">
The desktop app and local bots run on your computer, but today both need you
to sign in to a free HQ account. Signing in is free and does not need a card.
</Aside>

- **Desktop app.** Download it from the
  [releases page](https://github.com/indigoai-us/hq-desktop-app/releases/latest).
  It asks you to sign in when it first opens. To keep it from syncing, open
  Settings, then Sync, and turn off "Sync on launch", "Auto-sync", "Instant
  sync" and "Also sync my personal HQ files to the cloud".
- **Local bots.** `hq bot create <name>` sets up a bot that runs on your
  computer with your own AI model login. Each bot has an HQ identity, so it
  needs a sign-in.

## What needs the cloud

These features use the HQ cloud and need an HQ sign-in.

- Sync between computers and with teammates
- Sharing files, DMs and team membership
- Deploys (`/deploy`)
- Secrets stored in HQ
- Hosted agents, and local bots
- HQ MCP and integration calls

When you turn the cloud on, the [Free plan](/hq/guide/use-hq-for-free/)
includes $10 of usage each month. Deploys and DMs are free. Usage past $10 is
billed by use, and no card is needed until a month's usage passes $10.

## How synced files are encrypted

This only applies if you turn on sync. Files on your own computer are not
changed by HQ.

- Each company and each personal account gets its own storage bucket in the
  HQ cloud. Other accounts cannot read it.
- Files in that bucket are encrypted at rest. Depending on the account, the
  key is one made for that account alone, a key HQ manages, or Amazon S3's
  default encryption.
- HQ is not end-to-end encrypted. The HQ service can decrypt your synced files
  so it can sync and serve them.

More detail is in [Data security and encryption](/hq/security/4-data-security-encryption/).
