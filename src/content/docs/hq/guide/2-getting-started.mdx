## Prerequisites

- A Mac or Windows PC (Linux is not supported yet)
- **Claude Code**, **Codex**, or **Grok** if you want to finish setup in an AI tool
- An HQ account

## Install

1. Go to [hqforwork.com/install](https://hqforwork.com/install) and download HQ
   for your computer.
2. Open **HQ** and sign in.
3. Choose where your HQ workspace should live (the default is `~/hq`).
4. Select **Install** and let HQ finish setup. If you don't have a company yet,
   HQ asks you to name one or join an invite, then pick a plan.
5. On the **HQ is ready** screen, select **Open HQ Desktop**, or open the
   workspace in an AI tool with **Open in Claude Code** or **Open in Codex**.
   **Open in Grok** also appears when the Grok CLI is installed.

**Open HQ Desktop** opens the desktop app, where a Setup bot walks you through
the rest of setup in a chat. The AI tool buttons open the selected tool in your
workspace so you can run `/setup` there.

## Finish setup in your AI tool

Claude Code opens with `/setup` ready to run. In Codex, open the prompt and run:

```bash
/setup
```

The setup wizard asks one question at a time. You can skip any step and setup
still completes. It runs these phases:

| Phase | What it does |
|-------|--------------|
| **0a. Install manifest recovery** | Checks the tools the installer recorded and fixes anything missing |
| **0b. Dependencies and auth** | Installs missing tools such as the `hq` CLI, `qmd`, and `gh` |
| **0c. HQ Cloud** | Confirms your HQ login, claims invites, and makes sure sync is running |
| **0d. Prior AI footprint** | Offers to import context from AI tools you used before |
| **1. Identity** | Your name, what you do, your goals, your challenges, and your systems of record |
| **1.5. Social presence** | Optionally reads your public profiles to learn your voice |
| **2. Generate files** | Creates `repos/`, the `personal/` scaffold, and your profile files |
| **3. Summary** | Lists what was created |
| **4. HQ mental model** | Explains how HQ is organized |
| **4.5. Dream big** | Captures a longer-term vision for how you will use HQ |
| **5. What do you need help with?** | An interview that sets up what it can now and recommends commands to run next |
| **6. Welcome page and hand-off** | Deploys a private welcome page (when you are signed in) and hands you off to a fresh session |

Phase 2 writes your profile here:

```
personal/
├── knowledge/
│   ├── profile.md
│   └── voice-style.md
├── policies/
├── workers/
├── settings/
├── skills/
└── hooks/
agents-profile.md
```

Add a company with `/newcompany {slug}`. Company folders live at
`companies/{slug}/` with `settings/`, `data/`, `knowledge/`, `workers/`, and
`policies/`.

## First Task

After setup, try these:

```bash
# Find what to work on
/startwork

# Create a project
/prd "Build a landing page for my product"

# Run a worker
/run task-executor execute

# Search your HQ
/search "how do workers work"
```

## Directory Structure

```
hq/
├── .claude/             # Claude Code settings, hooks, and skills
│   └── skills/          # Slash commands
├── .codex/ .grok/ .cursor/ .agents/   # Other runtimes
├── AGENTS.md            # Shared agent instructions
├── companies/           # One folder per company, plus manifest.yaml
│   └── {company}/projects/{name}/prd.json
├── core/                # Files shipped with HQ (replaced by /update-hq)
│   ├── knowledge/public/  # Bundled knowledge bases
│   ├── workers/public/    # Bundled workers
│   └── policies/
├── personal/            # Your own knowledge, policies, workers, and skills
├── repos/
│   ├── public/          # Code repos
│   └── private/
└── workspace/
    ├── threads/         # Session history
    ├── checkpoints/     # Session saves
    ├── learnings/       # Captured insights
    └── reports/         # Generated reports
```
