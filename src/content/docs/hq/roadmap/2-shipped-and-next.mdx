The original combined repository has been split into independently versioned products, all live. This page records what shipped and what's next per product. For how the repos compose, see the [Ecosystem & Repo Map](/hq/architecture/2-ecosystem/).

## What shipped

HQ installs through the HQ desktop app (macOS and Windows) or from a terminal with `npx create-hq` (Node.js 22.13+ and git). The ecosystem is published and deployed:

- **Scaffold:** `hq-core` (`hqVersion` 16.0.x in `core/core.yaml`) seeds new instances. Existing ones update with `/update-hq` or `hq rescue`.
- **Installer:** `create-hq` downloads the scaffold and offers hq-cli and the recommended packs.
- **CLI + sync:** `@indigoai-us/hq-cli` (the `hq` command) and `@indigoai-us/hq-cloud` (the sync engine) are published to npm and version independently.
- **Desktop:** `hq-desktop-app` replaces the separate hq-sync, hq-sync-win, and hq-installer apps. It ships signed builds for macOS and Windows with auto-update.
- **Cloud apps:** `hq-console` (web console at `hq.computer`), `hq-deploy` (artifact data plane), and `hq-pro` (vault, teams, `VaultApi`, shared Cognito identity) are deployed on Vercel and AWS.
- **Content packs:** `hq-packages` distributes optional packs via `hq install`.
- **Runtimes:** the scaffold ships configuration for Claude Code, Codex, Cursor, and Grok.

## hq-core 16.0

16.0.0 is a breaking release.

- **Conduct mode by default.** Fresh interactive sessions open in `/conduct` mode. Unattended sessions (local bots, fleet boxes, scheduled jobs) are unaffected. Turn it off with `default_enabled: false` in `personal/settings/orchestrator.yaml`, `HQ_AUTO_CONDUCT=0`, or `/conduct off`.
- **v15 deprecations removed.** The `/plan` stub is gone; use `/prd`. Skills such as `/tdd` and `/diagnose` read `GLOSSARY.md` only (no `CONTEXT.md` fallback).
- **Engineering skills are back in core.** The v15.0.0 extraction into `hq-pack-engineering` was reversed: `/tdd`, `/review`, `/execute-task`, `/run-project`, `/land`, and the related workers ship in core again. Upgraders can remove the redundant pack with `hq packs uninstall hq-pack-engineering`.
- **hq-cli floor.** `core/core.yaml` sets `requiresHqCli: ">=5.345.67"`.

### Defaults

- **Permission mode `auto`.** `.claude/settings.json` ships `defaultMode: "auto"`. A v15 change to Plan mode was unintended and has been reverted.
- **Model alias `opus`.** Sessions and subagents use the `opus` alias, which Claude Code resolves to its newest Opus model. The 1M-context variant (`opus[1m]`) stays opt-in per command.

### Skills

- **`/humanize`** revises human-facing prose to remove generated-text tells.
- **`/work-broadcast`** composes team announcements with a draft-confirm step before sending.
- **`/hq-heal`** triages a runtime error mid-session and proposes a fix.
- **`/ontology`** is the interface to the hq-pro ontology (entity graph and per-company brief).
- **`/hq-share`** drafts a short factual note describing what is being shared, for the sender to review.
- **`/conduct-join`** attaches an already-running session to a `/conduct` session.

### Structure

- Top-level directories are `companies/`, `core/`, `personal/`, `repos/`, and `workspace/`; public HQ docs live in `core/docs/hq/`.
- `core/core.yaml` is the only shipped version manifest.

## Near-term priorities per product

### hq-desktop-app
- Conflict-resolution UX
- Richer per-file progress and notifications

### hq-pro + hq-console (teams)
- Membership management and role workflows
- Usage and deployment visibility in the console
- Vault and capability-grant ergonomics

### hq-cli + hq-cloud
- Sync reliability and resumability
- Schema-driven secret access ergonomics (see [hq-secrets](/hq/products/capabilities/hq-secrets/))

### hq-packages
- More first-party packs
- A smoother pack authoring and install loop

## How priorities are sized

Work is scoped by complexity and risk (S/M/L/XL), not by calendar dates. HQ runs many concurrent agent sessions, so effort is expressed as sessions of work and concurrency rather than weeks. External deadlines, when they exist, are tracked separately.
