Several ideas that used to be listed here have shipped:

| Former idea | Where it landed |
|-------------|-----------------|
| Worker marketplace | `hq publish` submits a skill or worker pack to the HQ marketplace; `hq creators` manages the creator account; `hq workers` discovers and shares workers |
| Team features | hq-pro companies, memberships, groups, and per-company vaults, with per-membership sync modes (`shared`, `all`, `custom`) |
| Native apps | iOS (beta) and Android apps in the hq-native-mobile repo |
| AI model flexibility | The scaffold ships configuration for Claude Code, Codex, and Grok, plus a rules file for Cursor |
| Integrations | `hq integrations` connects company apps (Linear, Notion, and others) through a governed gateway |
| CLI health and update | `hq doctor` checks hook wiring, runtimes, and connection health; `hq rescue` re-syncs HQ core to the latest release while preserving local edits |

## Homebrew Tap

**Idea:** `brew install` as an alternative to `npx create-hq`.

**Why:** no Node.js dependency for the installer itself.

**How:** a Homebrew tap with a formula that downloads a compiled installer binary.

## Real-Time Collaboration

**Idea:** multiple users editing the same file at once.

This needs operational transform or CRDT editing, a real-time update channel, and presence indicators. A smaller first step is file-level locking: when one user is editing a file, others see it as locked and read-only.

## CLI Improvements

- Tab completion for all commands (bash, zsh, fish)
- An export command for HQ snapshots (backup and sharing)
