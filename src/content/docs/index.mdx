Indigo HQ is the operating system for AI workers. It provides a shared context layer over Claude Code, Codex, and Grok (with a rules file for Cursor) that syncs knowledge, skills, policies, and capabilities across your team. It scales from a solo builder to an enterprise.

HQ ships as a **split ecosystem** of independently versioned products rather than one combined repository. This site is the comprehensive user and technical reference for all of them. To see how they compose, read the [Ecosystem & Repo Map](/hq/architecture/2-ecosystem/).

## Get started

The usual way to install HQ is the desktop app for macOS or Windows; see [Getting started](/hq/guide/2-getting-started/). From a terminal, with Node.js 22.13 or later and git:

```bash
npx create-hq
cd hq && claude
/setup
```

`create-hq` asks for a folder name and defaults to `hq`.

## Meetings & signals

Meetings and signals have shipped in HQ. `hq meetings` lists, searches, and prints meeting transcripts and notes, and can invite the meeting bot to a Google Meet, Zoom, or Teams call. `hq signals` reads signals such as action items and decisions for a company. In your AI tool, `/meeting-notes`, `/join-meeting`, and `/signals` read the same data. Documentation pages are pending; until then, run `hq meetings --help` and `hq signals --help`.
